TraceLens AI Technical Specification

TraceLens is an enterprise developer & support engineer AI assistant built for NEWTOWN Insurance Company. It integrates Vertex AI Reasoning Engine, Firestore incident memory, Cloud Storage asset pipeline, Python code sandbox execution, and A2UI dynamic UI component rendering.

Adaptive UI Schema Manager (`A2uiSchemaManager`)

TraceLens uses the **A2UI (Agent-to-UI)** schema protocol to return rich, structured UI cards, columns, option chips, and image assets dynamically inside the chat interface. Below is the active A2UI catalog schema structure:
